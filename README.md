
# Synthetic Medicare Analytics

## Project Overview

This project explores synthetic Medicare data from 2008–2010 to demonstrate an end-to-end healthcare data analytics workflow. The analysis focuses on beneficiary demographics, healthcare utilization, Medicare claims, service categories, and healthcare costs.

The project uses Python for data profiling and quality investigation, SQL Server for data cleaning and analysis, and Power BI and Tableau for data visualization.

**Note:** This project uses synthetic data for educational and portfolio purposes. It does not contain real Medicare beneficiary records.

## Tools and Technologies

- **Python:** Data profiling, anomaly investigation, data quality checks, cleaning, and relationship validation
- **SQL Server / T-SQL:** Data preparation, validation, analytical queries, and date dimension development
- **Power BI:** Interactive reporting and healthcare analytics visualizations
- **Tableau:** Dashboard development and data visualization
- **GitHub:** Project documentation and version-controlled portfolio files

## Project Workflow

1. **Data Profiling:** Examined source datasets, table structures, missing values, and duplicate records.
2. **Data Quality Investigation:** Investigated anomalies, claim segments, and potential orphaned outpatient records.
3. **Data Cleaning:** Developed Python and SQL workflows to prepare data for analysis.
4. **Relationship Validation:** Evaluated relationships between beneficiary, claim, and service data.
5. **SQL Analysis:** Created analytical queries and supporting date and geographic fields.
6. **Dashboard Development:** Built Power BI and Tableau visualizations to explore healthcare costs, beneficiaries, service categories, and Medicare claim activity.

## Key Analysis Areas

- Healthcare service costs over time
- Beneficiary counts by year
- Healthcare costs by service category
- Medicare claim activity
- Beneficiary geographic summaries
- Data quality and relationship validation
